# Alpha 810 公开契约（中文参考）

本站消费由 `money-trees` 生成的静态 Alpha 810 聚合研究快照，不执行因子计算、模型训练或完整回测。

## 快照身份

公开快照使用 `kind: moneytree_factor_evidence_snapshot` 和受支持的 schema 版本。Schema 1.0 包含全区间聚合 IC、RankIC、覆盖率和分组收益；Schema 1.1 增加年度与市场状态切片、Newey–West 不确定性诊断和全因子检验家族的多重检验结果。Schema 1.2 增加滞后阶数为 0、1、5、20、60 的 Newey–West/Bartlett 敏感性分析，以及逐因子的循环 20 交易日移动区块 bootstrap 区间。逐因子的滞后 q 值和标准误数组按照快照的 `lags` 列表排列。快照还需记录生成时间、数据版本、代码版本、样本、配置、因子记录、质量状态和公开限制。

## 可以公开的内容

- 因子名称和公开因子族标签。
- 日期范围、覆盖率、有效观测数和数据版本。
- 聚合 IC、RankIC、正值比例、分组均值以及年度或市场状态汇总。
- 若有提供，公开标准误、置信区间、原始 p 值和因子家族校正 q 值，包括各滞后阶数的 BY q 值及移动区块 bootstrap 区间。
- 生成时间、研究方法、质量警告和证据限制。

## 不公开的内容

- 逐股票因子值或收益。
- 组合权重、持仓、交易或执行结果。
- 原始输入路径、凭证、供应商映射或私有实现细节。

## 指标口径

- IC 和 RankIC 分别是每日横截面 Pearson 与 Spearman 相关系数。全区间均值仅对统计量有效的日期取平均。
- IR 是每日相关系数均值除以总体标准差；正值比例是有效日相关系数大于零的比例。
- 每日按有效因子值从低到高分成五组，G1 最低、G5 最高。快照对各组每日横截面平均收益再跨有效日期取简单平均。这是单期收益，不复利、不扣成本。
- 收益字段为 `next_period_return`，本次发布声明持有期为一个交易日。下一交易日收盘价收益是研究标签，不能证明可按该价格成交。
- 年度切片按自然年汇总同一组每日诊断。市场状态使用前 252 个交易日的沪深 300 收益复合值；正值为牛市状态 `bull`，否则为熊市状态 `bear`。当前日基准收益不用于该日标签。
- 原有 uncertainty 字段为兼容旧版保留零阶滞后、正态参考分布的双侧 Newey–West 结果。Schema 1.2 另行报告滞后阶数 0、1、5、20、60 下的 Bartlett/Newey–West 标准误和经过因子家族校正的 q 值。每个滞后阶数分别针对完整 810 因子家族重新进行 Benjamini–Yekutieli 校正；4 个没有有效 RankIC 检验的因子保留空值。循环移动区块 bootstrap 按 20 个交易日为区块重抽样 2,000 次，报告 RankIC 日均值的百分位数 95% 区间。滞后阶数是敏感性检查；bootstrap 区间仅作描述，不校正数据窥探。
- Benjamini–Yekutieli q 值针对 810 个因子的检验家族校正；Benjamini–Hochberg 用作敏感性比较。4 个因子没有有效检验，仍标为未检验。
- 质量检查会对覆盖率低于 80% 或缺少 RankIC 均值的因子告警。发布快照保留该警告；质量状态不代表因子表现。

## 证据限制

2016–2025 数值来自历史因子库输出。所有输入是否在历史时点可得尚未逐项独立核验；Alpha 101/191 的生成元数据特别提示行业输入应使用时点数据。年度、市场状态、HAC 滞后敏感性、移动区块 bootstrap 和多重检验视图都是对这份历史面板的描述性诊断，不能证明时点回测、样本外表现、可交易性或投资价值。

Alpha 810 是公开研究浏览器，不构成投资建议。生产者流程请见 [money-trees 公开文档](https://runchengxie.github.io/money-trees/)。
