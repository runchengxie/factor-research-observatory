# Study trust, reproduction and decision navigation

Each optional `data/study-navigation/<study-id>.json` is a reviewed owner projection. It records six separate trust dimensions, original run/record identity and missing provenance, acceptance-based decision tasks, and optional retrospective paired intervals, scale slices and forecast calibration. It never contains private reproduction paths, exact configurations, per-security rows or executable portfolio performance.

The owner registry is authoritative for these navigation decisions; source studies remain authoritative for methods and historical results. The English owner navigation note and its bilingual structured companion are enrolled in the knowledge pilot. Export only from a merged owner revision. The original run code revision can be null even when a current owner source revision is known; these are different identities. An artifact hash does not certify a full rerun.

## Presentation

The concise topic list remains at `/studies`; its evidence link opens `/studies/evidence`, which defaults to the research-problem matrix. Experiment-type and decision views use compact catalog metadata and do not fetch all optional assets. Negative/inconclusive filtering includes scoped unsuccessful comparisons, not protocol-only or unrun hypotheses. Detail routes load only their own navigation asset and preserve current findings if an optional asset is unavailable or malformed. Retry is localized.

A trust card displays announcement clock, original financial versions, historical universe, delisting/terminal handling, execution timing and transaction costs. `qualified` applies only within the named scope. `partial`, `unverified`, `failed`, `protocol_only` and `not_applicable` remain distinct.

## Retrospective diagnostics

R&D monthly intervals use paired circular 12-month blocks on the separately documented historical extension (90/80 sections), never spliced into the corrected 77/66 screen. Forecast error intervals resample issuers within one observed annual fold; they do not estimate market-time uncertainty. Different forecast targets have different training-fold transformed units. Positive MAE differences mean worse errors; positive IC differences mean higher association. No causal or executable-return claim follows.

Calibration selects one target/year/model because forecast bucket membership is model-specific. Empty buckets remain null. Current-revenue scale slices retain missing values as group 0; this is a scale proxy, not industry or market-cap neutrality. Small groups remain descriptive.

## Source review

The baseline auditor hashes optional navigation assets and the navigation authority document at its own merged source revision. Changes require review without rewriting conclusions automatically. Removing a previously reviewed optional asset is detected. Generated exports, retained receipts, snapshots and screenshots stay outside Git. The existing daily audit service runs against a stable production release.
