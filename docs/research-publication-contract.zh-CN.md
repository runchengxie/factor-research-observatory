# 研究发布契约

`quant-factor-observatory` 是公开投影层，不是私有研究的事实源。研究笔记仍由
所属仓库维护，只有经过审核的聚合投影才能发布到这里。

独立市场研究项目及其项目级方法由 `quant-market-research` 维护。本站负责因子目录组织、标准化因子专题、发布状态和符合本契约的审核投影。因子专题满足来源身份和审核要求后可以在本站展示；应链接到权威方法与证据，不复制整份源材料。私有策略证据仍由 `quant-research` 维护，只有单独审核通过的脱敏投影才能发布。

源笔记必须有稳定的 `knowledge/v1` 或 `knowledge/v2` 身份和 `authority_ref`。发布
manifest 记录源引用、研究状态、公开 ID 和发布状态；公开 ID 不能替代源文档身份。
每个研究专题在 manifest 和目录中都保留 `doc:quant-research...` 来源身份。系列投影
可以引用双语综述，单项研究则应指向其自身证据的权威笔记。目录可选填语言无关的
系列、市场、方法、频率和证据阶段；缺少这些分类的旧条目仍须安全展示。

公开研究专题可以包含标题、研究族、状态、摘要、区间、发现、限制和聚合结果行。
机器可读字段保持英文或语言无关；同一份聚合证据可以提供 `en-US` 和 `zh-CN`
两种展示语言。

投影必须排除私有数据路径、凭证、私有代码、逐股票信号、组合权重、执行细节和
精确私有因子算子。研究假设、初步诊断、已复核聚合结果和历史归档必须明确区分。
港股历史结论不得暗示可迁移到 A 股。没有证据时保留为研究假设或未发布状态，
不得补写虚构指标。

`site/public/data/research-publication-manifest.json` 是源笔记与静态站点之间可审计
的桥梁。发布测试会拒绝本地路径、凭证、逐股票字段和私有实现引用。
