# 研究发布契约

`quant-factor-observatory` 是公开投影层，不是私有研究的事实源。研究笔记仍由
所属仓库维护，只有经过审核的聚合投影才能发布到这里。

源笔记必须有稳定的 `knowledge/v1` 身份和 `authority_ref`。发布 manifest 记录
源引用、研究状态、公开 ID 和发布状态；公开 ID 不能替代源文档身份。

公开研究专题可以包含标题、研究族、状态、摘要、区间、发现、限制和聚合结果行。
机器可读字段保持英文或语言无关；同一份聚合证据可以提供 `en-US` 和 `zh-CN`
两种展示语言。

投影必须排除私有数据路径、凭证、私有代码、逐股票信号、组合权重、执行细节和
精确私有因子算子。没有证据时保留为研究假设或未发布状态，不得补写虚构指标。

`site/public/data/research-publication-manifest.json` 是源笔记与静态站点之间可审计
的桥梁。发布测试会拒绝本地路径、凭证、逐股票字段和私有实现引用。
