# 研究发布契约

`quant-factor-observatory` 是公开投影层，不是私有研究的事实源。研究笔记仍由
所属仓库维护，只有经过审核的聚合投影才能发布到这里。

独立市场研究项目及其项目级方法由 `quant-market-research` 维护。本站负责因子目录组织、标准化因子专题、发布状态和符合本契约的审核投影。因子专题满足来源身份和审核要求后可以在本站展示；应链接到权威方法与证据，不复制整份源材料。私有策略证据仍由 `quant-research` 维护，只有单独审核通过的脱敏投影才能发布。

源笔记必须有稳定的 `knowledge/v1` 或 `knowledge/v2` 身份和 `authority_ref`。发布
manifest 记录源引用、研究状态、公开 ID 和发布状态；公开 ID 不能替代源文档身份。
每个研究专题在 manifest 和目录中都保留 `doc:quant-research...` 来源身份。系列投影
可以引用双语综述，单项研究则应指向其自身证据的权威笔记。目录可选填语言无关的
系列、市场、方法、频率和证据阶段；缺少这些分类的旧条目仍须安全展示。

公开研究专题可以包含标题、研究族、状态、摘要、区间、发现、限制和聚合结果行。
机器可读字段保持英文或语言无关；同一份聚合证据可以提供 `en-US` 和 `zh-CN`
两种展示语言。

投影必须排除私有数据路径、凭证、私有代码、逐股票信号、组合权重、执行细节和
精确私有因子算子。研究假设、初步诊断、已复核聚合结果和历史归档必须明确区分。
港股历史结论不得暗示可迁移到 A 股。没有证据时保留为研究假设或未发布状态，
不得补写虚构指标。

`site/public/data/research-publication-manifest.json` 是源笔记与静态站点之间可审计
的桥梁。发布测试会拒绝本地路径、凭证、逐股票字段和私有实现引用。

## 研究探索展示

研究条目可以通过可选的 `exploration_asset` 指向 `data/study-exploration/` 下的补充数据，并用 `exploration_counts` 提供目录导航摘要。详情页只加载本项研究的数据；列表页不请求所有补充证据。缺少这些字段的旧条目继续正常呈现。

`observatory.study_exploration.v1` 记录研究身份、权威来源、来源版本、展示核对日期、证据阶段、双语来源、精选探索阶段、聚合图表及下一项研究问题。每个阶段说明问题、中间发现和据此作出的决定。它是整理后的证据路径，不代表独立实验数量或完整时序日志。早期正向、无效、被替代和负向结果保留原有解释，不拼入后来的修正指标。

图表必须声明指标、单位、样本与协议口径、解读和来源。系列共用类别顺序；缺失值为 null，不填零。不同预测目标、财务预测相关性、股票收益相关性、年化收益与主动累计收益分别标注。精确数值仍可通过表格读取。没有已复核结果的假设或协议不绘制绩效图。私有来源仅公开稳定身份与脱敏血缘，不暴露原始路径或实现。

补充证据加载或契约失败时保留主体内容，并提供本地化重试。原生 SVG 的控件和对应表格支持键盘阅读。新增展示必须同步发布清单并通过双语、来源、指标和公开发布检查。本节是英文契约的中文参考。

## 研究总览扩展

可选的 `evidence_summary`、`related_studies`、`source_review_status` 和探索资产的 `conclusion_changes` 遵循相同的已复核聚合边界。目录的 `research_hub` 登记允许展示的对照组与有来源依据的解释变化。内容哈希可作为公开元数据，私有路径与原始观测仍不得公开。基线复核与定时审计见 [研究证据总览中文参考](research-hub.zh-CN.md)。

可选研究导航资产及简要 `navigation_summary` 元数据遵循相同的聚合隐私边界。可信度、复现回执、决策任务与回溯区间／校准必须通过来源身份、单位、样本、空值和双语检查。参见 [研究证据导航](research-evidence-navigation.zh-CN.md)。
